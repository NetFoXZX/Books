# Changelog

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.17] - 2026-04-29

### Добавлено
- Улучшено извлечение названия книги со страницы описания Яндекс.Книг
- Название книги теперь берётся из элемента `CONTENT_TITLE_MAIN` (приоритетный источник)
- Добавлена поддержка извлечения названия из метаданных API для комиксов
- Добавлена поддержка извлечения названия из плейлиста для аудиокниг

### Исправлено
- Исправлена ошибка сохранения файлов под стандартными именами вместо названий книг
- Исправлена работа с IndexedDB для корректного сохранения имён файлов
- Улучшена обработка разных форматов данных при скачивании

### Улучшено
- Названия файлов теперь соответствуют названиям книг из страницы описания
- Улучшена очистка названий от служебных текстов ("слушать онлайн", "читать онлайн")
- Добавлена обратная совместимость для старых записей в хранилище

## [1.0.16] - 2026-04-28

### Добавлено
- Поддержка скачивания аудиокниг в формате MP3/M4A
- Поддержка скачивания комиксов в формате ZIP
- Автоматическая авторизация через cookies

### Улучшено
- Улучшена производительность скачивания больших файлов
- Добавлена разбивка архивов на части при превышении лимита размера

## [1.0.15] - 2026-04-27

### Добавлено
- Базовая функциональность скачивания EPUB
- Интерфейс расширения

### Исправлено
- Исправлены ошибки авторизации
