# Changelog

## [1.0.22] - 2026-05-13

### Добавлено
- Чекбокс "Проверить формат" при скачивании EPUB для валидации HTML файлов
- Сохранение состояния чекбокса в chrome.storage.local (запоминает последний выбор)
- Чекбокс отображается только для обычных книг (скрыт для аудиокниг и комиксов)
- Кнопка "Скачать EPUB" скрывается для аудиокниг без текстовой версии

### Изменено
- Чекбокс "Проверить формат" перемещён выше кнопки "Скачать EPUB"
- Чекбокс включён по умолчанию

### Добавлены функции валидации HTML (при включённой галке):
- Удаление `<!DOCTYPE...>` деклараций
- Удаление `&nbsp;` сущностей
- Удаление `<style>...</style>` разделов
- Замена `<br>` на `<br />`
- Добавление `<?xml version='1.0'?>` в начало файла
- Замена `<html>` на `<html xmlns="http://www.w3.org/1999/xhtml">`
- Замена `<meta>`, `<link>`, `<img>`, `<hr>` на самозакрывающиеся теги

## [1.0.18] - 2026-04-29

### Изменено
- Комиксы теперь скачиваются напрямую в формате `.cbz` (без сохранения в IndexedDB)
- Скачивание комиксов работает аналогично скачиванию EPUB - файл сохраняется сразу после подготовки

### Исправлено
- Исправлена ошибка `URL.createObjectURL is not a function` в Service Worker контексте
- MIME тип для комиксов изменён на `application/x-cbz` для правильного расширения файла

### Улучшено
- Приоритет названия для комиксов изменён: страница → API → фолбэк
- Упрощён код - нет необходимости хранить данные комиксов в IndexedDB

## [1.0.17] - 2026-04-29

### Добавлено
- Улучшено извлечение названия книги со страницы описания Яндекс.Книг
- Название книги теперь берётся из элемента `CONTENT_TITLE_MAIN` (приоритетный источник)
- Добавлена поддержка извлечения названия из метаданных API для комиксов
- Добавлена поддержка извлечения названия из плейлиста для аудиокниг

### Исправлено
- Исправлена ошибка сохранения файлов под стандартными именами вместо названий книг
- Исправлена работа с IndexedDB для корректного сохранения имён файлов
- Улучшена обработка разных форматов данных при скачивании

### Улучшено
- Названия файлов теперь соответствуют названиям книг из страницы описания
- Улучшена очистка названий от служебных текстов ("слушать онлайн", "читать онлайн")
- Добавлена обратная совместимость для старых записей в хранилище

## [1.0.16] - 2026-04-28

### Добавлено

### Улучшено
- Улучшена производительность скачивания больших файлов
- Добавлена разбивка архивов на части при превышении лимита размера
