# Yandex Books Downloader - Расширение для браузера

Это простое расширение для Yandex Browser (Chrome) для скачивания книг с books.yandex.ru в форматах EPUB, аудиокниги и комиксы.

## Особенности

- 📥 Скачивание книг в формате EPUB
- 🎧 Скачивание аудиокниг в формате MP3 (ZIP архив)
- 📚 Скачивание комиксов в формате ZIP (изображения страниц)
- 🔄 Автоматическое использование текущей сессии браузера
- 🔐 Автоматическая авторизация через cookies (для комиксов)
- 📖 Поддержка всех книг из вашей библиотеки
- ⚡ Быстрое скачивание и сборка
- 🎁 Валидация epub формата для обеспечения большей совместимости с разными читалками

## Использование

### Для электронных книг:

1. Откройте книгу на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите на значок расширения в панели инструментов <img width="36" height="34" alt="image" src="https://github.com/user-attachments/assets/88a1ed05-a4e8-43a0-a3ff-5720942f8e4a" />

3. **Чекбокс "Проверить формат"** (включён по умолчанию):
   - При включённой галке HTML файлы в EPUB архиве проходят валидацию и исправление
   - Это улучшает совместимость с некоторыми читалками EPUB
   
   
4. Нажмите "Скачать EPUB" (на значке расширения появится анимация)
5. Дождитесь завершения скачивания (анимированый зленеый квадрат пропадет)

### Для аудиокниг:

1. Откройте аудиокнигу на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите на значок расширения в панели инструментов
3. Нажмите "Скачать MP3"
4. Дождитесь завершения скачивания (ZIP архив с аудиофайлами)
5. По окончании загрузки нажмите "Скачать ZIP"
<img width="324" height="154" alt="image" src="https://github.com/user-attachments/assets/1ee2dc7b-5233-4fc6-a7eb-098edbdd6521" />
   
 

Аудиокниги сохраняются в ZIP архиве со структурой:
- `0001_*.mp3` или `0001_*.ogg` - первая часть/глава
- `0002_*.mp3` или `0002_*.ogg` - вторая часть/глава
- и т.д.

Файлы именованы с ведущими нулями для правильной сортировки.

Если общий объем файлов превышает 950Мб архив бьется на части, это предотвращает ошибку переполнения памяти.

### Для комиксов:

1. Откройте комикс на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите на значок расширения в панели инструментов
3. Если статус "🔒 Не авторизован" - нажмите "Войти в Яндекс Книги" и войдите в аккаунт
4. Нажмите "Скачать Комикс"
5. Дождитесь завершения скачивания (диалог сохранения файла)

**Примечание:** Для скачивания комиксов требуется авторизация в Яндекс. Авторизация происходит автоматически через cookies вашего браузера. Если токен не найден, откройте books.yandex.ru и войдите в аккаунт.

Комиксы скачиваются в формате `.cbz` (Comic Book Zip) - это ZIP архив с изображениями страниц:
- `Название_комикса/page00000000.jpeg` - первая страница
- `Название_комикса/page00000001.jpeg` - вторая страница
- и т.д.

Страницы именованы с ведущими нулями для правильной сортировки. Файл `.cbz` можно открыть в большинстве читалок комиксов (CBZ/CBR readers).

## Авторизация

Для скачивания комиксов требуется авторизация в Яндекс. Расширение автоматически получает `auth-token` из cookies вашего браузера.

**Если авторизация не требуется:**
- Вы уже вошли в Яндекс на books.yandex.ru
- Статус в popup показывает "🔓 Авторизован (автоматически)"

**Если требуется авторизация:**
- Статус в popup показывает "🔒 Войдите в Яндекс на books.yandex.ru"
- Нажмите кнопку "Войти в Яндекс Книги"
- Войдите в свой аккаунт
- Вернитесь в popup - статус изменится на "Авторизован"

## Технические детали

### Как это работает

1. **Content Script** (`content.js`) - внедряется на страницы reader и извлекает BookId из URL
2. **Popup** (`popup.html/js/css`) - интерфейс для управления скачиванием
3. **Background Script** (`background.js`) - основная логика:
   - Получает Session_id cookie из браузера
   - Запрашивает секрет для расшифровки
   - Загружает и расшифровывает метаданные книги
   - Скачивает контент (HTML, CSS, изображения)
   - Создаёт EPUB файл (ZIP архив)
   - Запускает скачивание через Chrome Downloads API

### API Yandex Books

- `GET /reader/p/api/v5/metadata_secret` - получение секрета для расшифровки
- `GET /p/api/v5/books/{bookId}/metadata/v4` - получение зашифрованных метаданных
- `GET /p/a/4/d/{uuid}/contents/OEBPS/{file}` - получение контента книги
- `GET /p/api/v5/comicbooks/{comicBookId}/metadata` - получение метаданных комикса (требует auth-token)
- `GET {zip_url}` - получение готового ZIP архива комикса

### Формат EPUB

EPUB - это ZIP архив со специальной структурой:
- `mimetype` - тип контента (без сжатия)
- `META-INF/container.xml` - путь к package файлу
- `OEBPS/content.opf` - метаданные и манифест
- `OEBPS/toc.ncx` - оглавление
- `OEBPS/*.html` - контент книги
