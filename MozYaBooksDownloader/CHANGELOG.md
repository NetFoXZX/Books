# Changelog

## [1.0.2] - 2026-05-15

### Добавлено
- Опция "✅ Проверить формат EPUB" при скачивании книг
- Сохранение состояния опции проверки формата между сессиями
- Автоматическое форматирование HTML страниц в EPUB (включено по умолчанию)

### Изменения
- Чекбокс проверки формата скрыт для аудиокниг и комиксов
- Кнопка "Скачать EPUB" не отображается для страниц только с аудиокнигой

## [1.0.1] - 2026-05-06

### Добавлено
- Скачивание книг в формате EPUB
- Скачивание аудиокниг в формате ZIP (без сжатия, m4a файлы)
- Скачивание комиксов в формате CBZ (ZIP с изображениями)
- Авторизация через OAuth Яндекс
- Сохранение файлов в локальное хранилище браузера (localForage/IndexedDB)
- Уведомления о готовности архивов
- Кнопка очистки хранилища

### Технические особенности
- Поддержка Manifest V2 для Firefox
- Использование localForage для работы с IndexedDB
- JSZip для создания архивов
- OAuth авторизация для доступа к комиксам
- Поддержка split-архивов для больших аудиокниг

### Изменения
- Исправлена ошибка с `host_permissions` в Manifest V2
- Заменено `browser.downloads.download()` на метод через `<a>` элемент для надёжности
