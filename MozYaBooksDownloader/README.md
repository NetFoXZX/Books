# 📚 Yandex Books Downloader

Расширение для браузера Firefox для скачивания книг, аудиокниг и комиксов с Yandex Books.

## 🚀 Возможности

- **Скачивание книг** в формате EPUB
- **Скачивание аудиокниг** в формате ZIP (без сжатия, m4a файлы)
- **Скачивание комиксов** в формате CBZ (ZIP с изображениями)
- Авторизация через OAuth Яндекс
- Сохранение файлов в локальное хранилище браузера

## 📋 Требования

- Firefox 109.0 или выше

## 🛠 Установка

1. Скачайте исходный код репозитория
2. Откройте Firefox и перейдите на `about:debugging`
3. Нажмите "Это Firefox" (This Firefox)
4. Нажмите "Загрузить временное дополнение" (Load Temporary Add-on)
5. Выберите файл `manifest.json` из папки расширения

> **Примечание:** Временное дополнение нужно перезагружать при каждом перезапуске браузера. Для постоянной установки используйте процесс упаковки расширения.

## ⚙️ Настройка для установки неподписанных дополнений

Для установки неподписанных дополнений в Firefox необходимо отключить проверку подписей:

1. В адресной строке введите `about:config` и нажмите Enter
2. Нажмите "Принять риск и продолжить"
3. В поле поиска введите и измените следующие параметры на `false`:
   - `xpinstall.signatures.required` → `false` (для расширений)
   - `extensions.langpacks.signatures.required` → `false` (для языковых пакетов)

> **Внимание:** Отключение проверки подписей снижает безопасность. Используйте только для доверенных расширений.

## 💾 Как использовать

### Скачивание книг (EPUB)

1. Откройте страницу книги на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите на иконку расширения
3. Нажмите кнопку "📥 Скачать EPUB"
4. После завершения скачивания нажмите "Обновить" в popup
5. Появится уведомление "Готов архив!" - нажмите "💾 Скачать ZIP"

### Скачивание аудиокниг (ZIP)

1. Откройте страницу аудиокниги на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите на иконку расширения
3. Нажмите кнопку "🎧 Скачать Audio"
4. После завершения (бейдж "✓" на иконке) нажмите "Обновить" в popup
5. Появится уведомление "Готов архив!" - нажмите "💾 Скачать ZIP"

### Скачивание комиксов (CBZ)

1. Откройте страницу комикса на [books.yandex.ru](https://books.yandex.ru)
2. Нажмите "Авторизоваться" если вы не авторизованы
3. Нажмите кнопку "📖 Скачать Комикс"
4. После завершения (бейдж "✓" на иконке) нажмите "Обновить" в popup
5. Появится уведомление "Готов архив!" - нажмите "💾 Скачать ZIP"

## 🔐 Авторизация

Для скачивания комиксов требуется авторизация в аккаунте Яндекс:

1. Нажмите кнопку "🔄 Открыть books.yandex.ru"
2. Войдите в свой аккаунт Яндекс
3. После успешной авторизации кнопка изменится на "Авторизован"

## 🗑️ Очистка хранилища

Если хранилище заполнено, нажмите кнопку "🗑️ Очистить хранилище" для удаления всех сохранённых файлов.

## 📁 Форматы файлов

| Тип | Формат | Описание |
|-----|--------|----------|
| Книги | EPUB | Стандартный формат электронных книг |
| Аудиокниги | ZIP | Архив без сжатия с m4a аудиофайлами |
| Комиксы | CBZ | ZIP архив с изображениями страниц |
